# Какие API предлагать

По умолчанию проверка идёт на одном API — 35. Остальные API агент предлагает с причиной,
решает человек. Каждый лишний API добавляет кадры и время, но параллельный прогон
на трёх эмуляторах идёт почти так же долго, как на одном.

| Что меняется в правке | API | Почему |
|---|---|---|
| Инсеты, навбар, статус-бар, BottomSheet, IME | 28, 33, 35 | 35 принудительно включает edge-to-edge для targetSdk 35. На 29+ есть жестовая навигация. 28 — старое поведение инсетов |
| Жестовая навигация, системный «назад» | 33, 35 (+ `nav=threebutton,gestural`) | жестов нет до API 29. Predictive back появился в 33 через opt-in приложения. В 35 системные анимации «назад» работают без developer options |
| Тёмная тема | 33, 35 (+ `theme=light,dark`) | на API 28 `cmd uimode night yes` системные «Настройки» не затемнил: дифф 0,2% в смоуке 15.10.2026 |
| Разрешения: уведомления, фото, геолокация | 32, 33, 34 | `POST_NOTIFICATIONS` с 33. Выбор отдельных фото с 34 |
| Шрифты, масштаб, длинные строки | 35 (+ `font=1.0,1.3`) | от API почти не зависит, нужен только масштаб |
| Чистая вёрстка без системных частей | 35 | одного API хватает |
| Фоновая работа, foreground service | 33, 34, 35 | типы FGS обязательны с 34. Ограничения на старт из фона растут с каждой версией |
| Per-app locale | 33, 35 (+ `locale=…` и пакет приложения) | `cmd locale set-app-locales` есть с 33 |

Как предлагать, пример:
«Правка трогает инсеты шторки. Предлагаю 28, 33, 35: на 35 обязателен edge-to-edge,
на 28 — старые инсеты. Матрица: `nav=threebutton,gestural`, на 28 жестов нет. Ок?»

## Оси матрицы `adbm run --matrix`

| Ось | Значения | Что делает `adbm prep` |
|---|---|---|
| `theme` | `light`, `dark` | `cmd uimode night no|yes` |
| `nav` | `threebutton`, `gestural` | `cmd overlay enable-exclusive …navbar.<x>`, на API < 29 ячейка `gestural` пропускается |
| `font` | число, например `1.0,1.3` | `settings put system font_scale` |
| `locale` | `ru-RU,en-US` | `cmd locale set-app-locales <пакет>`, только API 33+ |

Каждая ячейка — отдельная подпапка группы. Подпапки идут в порядке осей в `--matrix`:
`--matrix "nav=…" "theme=…"` даёт `api35/after/gestural/dark/1-peek.png`.
Перед прогоном ячейки `adbm run` удаляет её старые кадры, чтобы не смешать попытки.
